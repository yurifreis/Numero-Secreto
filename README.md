## Sobre o Jogo
A ideia do jogo/projeto veio por meio da formação da alura que estou estudando, onde grande parte dos cursos que abordam lógica de programação, possuem como referência esse jogo/projeto.  
  
Então no inicio do curso, quando foi apresentado o tamplet com toda a sua estrutura visual, eu pensei e decidi criar de forma separada e independente uma estrutura do zero, com foco em rever alguns conceitos não somente de estilização, mas também de lógica.

A construção do jogo foi feita sem a definição de um escopo fechado ou pre-definido. Defini que iria rever alguns conceitos e fui adequando a estrutura jogo para colocar esses conceitos em prática. A estrutura dos arquivos do jogo é formada por:
- index.html - arquivo html - estrutura;
- style.css - arquivo css - estilo;
- main.js - arquivo.js - lógica;

Armazenados de forma simples e organizada para fácil acesso. Dentre os conceitos que revi, foi sobre o escopo global e local envolvendo funções e variáveis, o código possui algumas funções e elas precisam ser executadas/chamadas e saber onde e como tratar as suas variáveis dentro e fora delas foi algo interessante para mim. Outra questão foi envolvendo estilização, especificamente com media querys/responsividade, o jogo é responsivo e gera quebras de estilo. Para o desenvolvimento do jogo utlizei as seguintes **tecnologias: html - css - js - git e github**
